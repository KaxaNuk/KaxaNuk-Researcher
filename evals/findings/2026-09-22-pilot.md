### F-01  `/blueprint 1` binds the experiment number to the strategy's path
- skill / layer / case: `blueprint`, `brainstorm`, `challenge` / contract / none: every blueprint
  case invokes `/kaxanuk-researcher-evals:blueprint . 1` until this is decided
- before: confirmed in a probe run, not by a case   after: pass — the four
  `contract/blueprint/*` cases, invoked as `/kaxanuk-researcher-evals:blueprint 1`, 3/3 each
  (`refuse-empty-universe`, `refuse-filled`, `refuse-no-claims`, `waits-before-write`), and
  `quality/blueprint/predictions-cite` 3/3
- root cause: contradiction — `.apm/prompts/blueprint.prompt.md:3-5`,
  `.apm/prompts/brainstorm.prompt.md:3-6` and `.apm/prompts/challenge.prompt.md:3-5` declare
  `input: [strategy, experiment]` (brainstorm adds `idea`), the strategy "Optional" but first. APM
  installs them as `arguments: [strategy, experiment]` with `argument-hint: <strategy> <experiment>`
  ("Mapped input -> command arguments in blueprint.md: [strategy, experiment]"), and Claude Code
  binds arguments by position, so an argument can be left out only when it is last.
- evidence: `/blueprint 1` expanded to "`` is the experiment number `N`; `1` is the strategy's
  path": `$strategy` is `1` and `$experiment` is empty. `/blueprint . 1` expands correctly.
- fix: decided a) by the owner, 2026-09-23: the experiment first in `blueprint`, `brainstorm` and
  `challenge`. Was: proposal — a) put the experiment first in all three, `input: [experiment,
  strategy]` (brainstorm: where `idea` goes is part of the call), so `/blueprint 1` works in the
  session's strategy and `/blueprint 1 ../other` names another; b) keep the order and make the
  argument hint and the text require the strategy's path, `/blueprint . 1`. Recommended: a), because
  the common case is the session already open in the strategy, and the text calls the path optional.
  Fixed in f79631e: `blueprint` and `challenge` take `[experiment, strategy]` and `brainstorm`
  `[experiment, idea, strategy]`, its text saying a multi-word idea is quoted and a path without
  an idea follows `""`; README, eval README, the four contract prompts and the home's `AGENTS.md`
  (home 0.7.1) use the new order (contract/blueprint 4/4 in one run each, quality/blueprint 1/1).
- verify: after a), change the four `contract/blueprint/*` prompts to
  `/kaxanuk-researcher-evals:blueprint 1`, then
  `uv run --no-project --with pypdf python tools/eval_run.py --case 'contract/blueprint/*' --max-cost-usd 9`

### F-02  `query` names works from memory where the reading map has none
- skill / layer / case: `query` / contract / `contract/query/names-the-gap`
- before: fail 0/3 with the new grader `no-work-from-memory`, on the three answers of
  `20260923T012105Z-diagnose-names-the-gap` (the baseline's answers were not kept; its three runs
  passed the four graders it had then)   after: pass — `contract/query/names-the-gap` 3/3,
  `no-work-from-memory` included; `contract/query/cites-notes` 3/3, `quality/query/claims-trace`
  3/3 and `quality/query/newer-claim-wins` 3/3
- root cause: ambiguous — `.apm/skills/query/SKILL.md:60-66`. Step 8 names a work "by year, authors
  and title when `references/reading-map.md` ... lists one ... and otherwise the kind of source";
  its next sentence, "Do not fill a gap from memory without saying you did", reads as leave to do so
  when said. The map lists no work on the Kelly criterion; all three runs named some anyway.
- evidence: "This suggestion is my own general knowledge, not from your library or the reading map:
  J. L. Kelly Jr. (1956), *A New Interpretation of Information Rate*, and E. O. Thorp's papers";
  another run adds MacLean, Thorp & Ziemba (2011); the third names "Kelly's original 1956 paper" and
  calls it "a description of what to look for, not a work from the reading map".
- fix: decided a) by the owner, 2026-09-23: outside the reading map, only the kind of source,
  never a work named from memory. Was: proposal — a) keep the rule as step 8 states it: outside
  the map, the kind of source only, and reword the last sentence so it covers answering from
  memory, not naming works; b) allow a named work from memory, labelled *from general knowledge,
  not in the reading map*, written into step 8 beside the map's label, and drop the new grader.
  Recommended: a), because the map's label exists so that every named work is one the package
  vouches for.
  Fixed in 0a1c2a9: step 8 says that outside the map no work is named, not even labelled as
  memory, and its last sentence covers answering from memory; query 0.4.1 (contract/query 6/6,
  quality/query 2/2).
- verify: uv run --no-project --with pypdf python tools/eval_run.py --case 'contract/query/names-the-gap' --max-cost-usd 2

  and addressed to the owner): lines 79-80 say that the blockquote stays whole, its last line
  included, because deleting it is the owner's act at the commit. (Task 11: commit and one
